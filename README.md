# Столовая — мобильное приложение

Отдельный Expo/React Native проект в `D:\projects\arkadiy\mobile`. Соседние проекты: `cafe-adminpanel` и `cafe-server`, оба на ветке `dev`.

## Запуск через Expo Go

```bash
cd D:\projects\arkadiy\mobile
npm ci
npx expo start
```

Онбординг появляется при первом запуске. Флаг хранится под ключом `cafe:onboarding:v2` в AsyncStorage. Повторно пройти его можно через «Сбросить все данные» в профиле.

## Текущий объём

Главная, меню по дате с комплексами и отдельными блюдами, детали блюда и комплекса в общей системе модальных окон, корзина, оформление с адресом и временем доставки, демонстрационная история заказов и экран входа. Главная, меню, детали и корзина оформлены в едином светлом стиле с глубоким зелёным акцентом. Фотоколлажи комплексов собираются из фотографий входящих блюд. Данные меню локальные; заказ сохраняется только в памяти процесса. Экран входа пока не отправляет номер. Фото в `assets/meals` демонстрационные. Пищевая ценность и варианты порций не выводятся, потому что моковые данные их не содержат.

В меню видны понедельник–суббота текущей или ближайшей рабочей недели. Прошедшие дни недоступны, воскресенье — выходной. В демо понедельник–четверг содержат полное меню, пятница — блюда без комплексов, суббота — неопубликованное меню. Категории без блюд скрыты. При смене даты корзина очищается после подтверждения. Добавление комплекса кладёт в корзину входящие в него блюда; к ним можно добавить любые отдельные позиции текущего дня. Оформление проверяет обязательные поля адреса и выбранный слот, затем показывает подтверждение и создаёт локальный демо-заказ.

## Контракт сервера

В `cafe-server/dev` уже есть реальные схемы: `CategoryRead`, `DishRead`, `MenuPublicRead`, `OrderCreate`, `OrderDetail`, OTP-авторизация и адреса. Основные публичные маршруты под `/api/v1`: `GET /menus/{menu_date}`, `POST /auth/otp/request`, `POST /auth/otp/verify`, `POST /orders`, `GET /orders`. Заказ требует авторизованного пользователя, адрес, дату/время доставки и `Idempotency-Key`. Денежные значения в JSON представлены десятичными строками. Черновые клиентские типы перечислены в `src/shared/api/serverContract.ts`.

Корзина уже хранит `menu_item_id`, а экран оформления формирует объект `OrderCreate`. Для настоящего заказа потребуется загрузить `MenuPublicRead.items`, доступные комплексы и слоты с сервера, авторизовать пользователя, создать или выбрать сохранённый адрес вместо демонстрационного `address_id: 1`, затем отправить заказ с `Idempotency-Key`. Локальный демо-заказ ничего не отправляет в API.

## Структура

- `src/app` — маршруты Expo Router и первый запуск;
- `src/pages` — экраны;
- `src/widgets` — оболочка, навигация и состояние сеанса;
- `src/features` — корзина;
- `src/entities` — локальная модель блюда;
- `src/shared` — тема и типы API.

Проверки: `npx tsc --noEmit`, `npx expo lint`, `npx expo export --platform android`.
